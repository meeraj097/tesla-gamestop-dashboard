# 📊 Tesla & GameStop Stock Analysis Dashboard

## 🚀 Overview

This project analyzes stock price and revenue data for Tesla and GameStop using Python. It includes data extraction, web scraping, cleaning, and visualization.

---

## 🛠️ Tech Stack

* Python
* Pandas
* BeautifulSoup
* Matplotlib
* yfinance

---

## 📈 What I Did

* Extracted stock data using yfinance
* Scraped revenue data from websites
* Cleaned and processed financial data
* Built visual dashboards using matplotlib
